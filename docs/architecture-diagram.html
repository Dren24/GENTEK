AI Pipeline Flow
1
INPUT: User submits text via POST /analyze
2
PATTERN DETECTION: Scan for 19 bias patterns (Male, Female, Stereotypes)
3
COUNTING & CATEGORIZATION: Tally occurrences by bias type
4
CLASSIFICATION: Assign bias category based on counts
5
SCORING: Calculate 0–100 bias intensity score
6
OUTPUT: Return results (patterns, classification, score, suggestions)
7
PERSISTENCE: Save to analysis table with user ID, text, score, classification, timestamp
↓
🗄️ Data Layer (SQLite + SQLAlchemy)
USERS Table
  • id (PK)
  • name, email
  • password (bcrypt hash)
  • email_notifications
  • created_at
ANALYSES Table
  • id (PK)
  • user_id (FK → users)
  • label, text
  • score, classification
  • created_at
RESET TOKENS Table
  • id (PK)
  • user_id (FK → users)
  • token (urlsafe 32-byte)
  • expires_at (1-hour TTL)
